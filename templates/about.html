About secblog

secblog is a public, searchable archive of security research blog posts. It collects feed metadata from hundreds of blogs, tags them with a free security taxonomy, and publishes a static site (GitHub Pages) that is updated by GitHub Actions.

Content policy

  • The public site shows metadata only: title, author, date, blog, category, tags, and a short excerpt (≤ ~300 characters) taken from the feed description with HTML stripped.
  • Full post text is never stored or published in this repository.
  • The Tools section indexes public GitHub repository metadata and links only — descriptions, stars, topics, categories. Tool source code and binaries are never downloaded, hosted, or mirrored.
  • Every card links to the original URL and to a Wayback Machine snapshot (https://web.archive.org/web/<url>).
  • Blogs marked dead (including domains hijacked by spam or parking) are never fetched or linked live; only Wayback snapshots are ingested and shown.
  • Excerpts and titles remain copyright of their respective authors; this archive is a discovery index, not a republication.

How it works

  1. sources.yaml — hand-editable registry of blogs and feed URLs.
  2. Python collector polls RSS/Atom (with ETag / Last-Modified), with a separate resumable backfill for history (Blogspot / WordPress paging, sitemaps, Wayback CDX for dead blogs).
  3. Deterministic tagging from config/taxonomy.yaml (optional LLM hook behind SECBLOG_LLM_TAGGER, off by default).
  4. Static site (Jinja2) + Pagefind client-side search.
  5. GitHub Tools monitor (config/github_watch.yaml) watches red-team orgs/accounts, parses curated lists (e.g. awesome-bof, Cobalt Strike Community Kit), and runs modest discovery searches — then publishes a filterable Tools page.
  6. GitHub Actions collects every 6 hours, backfills weekly, and deploys to Pages.
